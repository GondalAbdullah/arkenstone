# Architecture Decision Records

This folder records the significant decisions made about this app, why they
were made, and what alternatives were considered. Format follows the
lightweight [Nygard ADR](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) style.

When making a change that alters how the app is structured, stores data, or
behaves in a way future contributors (including future-you) would need
context to safely change again — add a new numbered ADR here rather than
only describing it in a commit message.
